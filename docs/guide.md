# 面板使用说明

这里记录面板里操作较多的功能。命令和文件格式见 [shape-key-system-api.md](plans/shape-key-system-api.md)。

## 表情详情：映射编辑

在「进阶 → 表情详情」里点击形态键名称，可以展开它的映射。「＋ 新建映射」可以从已扫描的网格里选形态键，也可以直接输入名称。部位分为眉、眼、视线、鼻·颊、嘴、下颌、舌和扩展。

- 节点类型有：面部信号、求和（sum）、取最大值（max）、取最小值（min）、相乘（mul）、相减（sub）、引用其他映射、原始 fcParam、常量和眼球旋转。混合节点可以继续展开，添加或移除输入。
- 编辑界面分为「映射结构」和「当前节点设置」两部分。结构树显示混合关系、信号名、fcParam 和系数；点击一个节点，只编辑这个节点。窗口宽时左右分栏，窄时上下排列。映射说明、标记和网格匹配规则默认折叠。编辑期间，通道列表和全局强度控件暂时收起。
- 形态键名称和面部信号用可输入的选择框，输入时下方会过滤候选。形态键按名称搜索，也可以直接输入还没扫描到的名称。信号可以按别名、fcParam 或用途搜索，但只有选中候选才会改动绑定。
- 信号候选会显示语义别名（如 `blink.L`）、骨骼名（`fcParam_001`）、用途、角色的左右侧、实时值，以及是否为推测。
- 每个输入可以设置系数和响应曲线（死区、幂指数、增益）。映射本身可以编辑说明、扩展和推测标记、其他网格名称以及排除规则。
- 「应用映射」会让修改立即在运行中的配置里生效；「取消编辑」会丢掉还没应用的草稿。「保存映射」写入用户配置。内置配置或 mod 自带的配置需要另起名字，保存到 `data/ShapeKeySystem/user/profiles/`，原文件不会被改动。保存后可以点「设为默认」，把它绑定到当前装备。
- 「恢复配置」会放弃还没保存的运行中修改。引用成环、未知信号和无效数值都会被拒绝；还被其他节点引用的映射不能删除。切换配置之前，需要先保存或恢复映射。

## 表情详情：面部动画测试

「视线设置」下方有一个可折叠的「面部动画测试」，用来回放录制好的面部动画，检查映射效果。

- 可以暂停、循环、调整速度（0.25～2 倍）和拖动跳转。「原版输入」模式把录制注入游戏，游戏原版表情和 SKS 会一起响应；「最终信号」模式只驱动 SKS。
- 下方的分析按本次播放中各信号的命中次数排序，显示信号用途和它在当前配置里绑定的形态键。支持分页和只看未绑定的信号，也可以直接为信号新建映射。
- 播放通过游戏适配器的可选接口 `playback` 运行。目前只有荒野实现了这个接口，其他游戏会显示不可用。
- 内置录制放在 `builtin/mhwilds/recordings/`，参数表是同一目录下的 `recording_catalog.json`。用户自己的录制放在 `user/recordings/`；旧目录 `user/games/mhwilds/recordings/` 仍然能读到，两边有同名文件时以新目录为准。
