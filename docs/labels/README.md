# 形态键译名

`shape-key-survey.tsv` 是内置译名表 `builtin/labels.json` 的来源记录：常见 VRChat、MMD 模型和服装、头发包里出现的形态键，加上 SKS 内置表情配置和别名表里用到的名字，共 5912 个（按匹配规则合并同名后）。

| 列 | 说明 |
|---|---|
| 原名 | 最常见的写法；其他写法在最后一列 |
| 中文名 | 译名（人工审过一遍） |
| 类别 | 表情、脸型、身体、服装、头发、饰品、其他、分隔线 |
| 确定 | 「否」表示含义只是猜测 |
| 已看图 | 在 Blender 里把形态键调到 1 对比过：「看到变化」或「看不出」（在嘴里、被遮住、变化太小）；空白表示只按名字翻译 |
| 模型数、出现在 | 在多少个模型里出现、是哪些 |
| 配置/别名 | 用到这个名字的内置表情配置或别名组 |
| 备注 | 不确定的原因 |

写进 `labels.json` 的规则：

- 只收「确定」为「是」的行，按类别分成 `avatar_expr`、`avatar_face`、`avatar_body`、`avatar_cloth`、`avatar_hair`、`avatar_acc`、`avatar_other` 几组；ARKit、MMD 的名字仍在原来的 `arkit`、`mmd`、`sks_mmd` 组里。
- 「确定」为「否」的 961 行不进界面，留在这张表里，确认以后把「确定」改成「是」再同步进 `labels.json`。
- 分隔线（`=====FACE=====` 这类）不翻译。

没覆盖到的：压缩包里没解开的模型；PMX 模型、MANUKA 的 FBX、希诺宁、pet.blend 里不确定的键没能在 Blender 里看图，只按名字判断。
