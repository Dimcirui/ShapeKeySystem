# ShapeKeySystem 1.14.0

## 新增

- **表情镜**：支持生化危机4 重制版；RE4R 的镜子里只有玩家，场景物件不会挡脸
- **表情镜**：可按部位隐藏（荒野按头盔、躯干、腕部、腰部、腿部、挂件、武器，RE4R 按躯干、武器），武器默认隐藏
- **表情镜**：定位点新增脖子；「对准定位点」让镜头正对所选定位点
- **设置与调试**：基础设置页显示运行环境（游戏、REFramework、绘制方式、面捕接收插件、表情镜状态）

## 变更

- **面板**：相关页面合并为标签页：表情详情并入「表情」，条件规则、总体绑定管理（原总体绑定与配置）、设置与调试、面捕各分为几个标签页
