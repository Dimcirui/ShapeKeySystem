# ShapeKeySystem 1.9.0

## 新增

### 驱动（进阶）
让形态键随时间或游戏状态自己动起来，优先于表情和捏脸；面捕或其他插件正在控制的形态键会先让给它们。
- **波形与公式**：正弦、三角、锯齿、方波、随机平滑，或自己写公式，可设周期、相位和最低 / 最高值
- **驱动组**：先算几个变量，再让多个形态键读同一个值一起变化；公式支持比较和随机数
- **与条件规则联动**：读取条件规则组合的进度，并可给开关配上自己的淡入淡出，做出瞄准时光环先消失、再到另一处旋转出现这类分阶段动画

- **多角色编辑（RE4）**：过场、同伴等场景里有多个角色时，标题栏可以切换正在编辑的角色；同一个人的玩家本体、过场副本和鉴赏雕像共用一套配置
- **RE9（实验性）**：里昂默认头部支持捏脸和普通场景的自动表情；过场、其他角色、身体和头发暂不支持
- **表情配置自动匹配**：全局配置驱动不了身上的部件时，自动换成匹配最多的配置，MMD、VRC 命名的 mod 不用再手动匹配

## 变更

- **条件规则**：添加形态键时可以输入文字搜索

## 修复

- **RE4 模型鉴赏**：鉴赏中的里昂、艾达雕像可以捏脸和驱动，里昂的其他服装头部也能识别
- **表情配置**：游戏读不到个别信号时，ARKit、MMD 等共用配置不再整份失效
- **搜索框**：输入文字搜索后点一下结果就能选中
