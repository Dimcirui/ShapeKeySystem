# ShapeKeySystem 1.16.0

## 新增

- **条件**（RE4R）：新增「持械中」和「手持武器类型」（枪械、刀、投掷物、徒手、其他）
- **条件**（RE4R）：同一动作的几个阶段合成一个条件，包括持械、射击动作、近战动作、招架、武器操作、移动、空中、特殊移动、受击、血量变化；已有配置里的单项条件照常生效
- **条件状态**：被独占状态挡住的状态显示被哪个状态覆盖，各状态前加形状标识

## 变更

- **性能**（RE4R）：表情驱动的每帧开销降到原来的三分之一左右，换装和场景切换时的停顿缩短；随包新增 `plugins/ShapeKeySystem_Native.dll`

## 修复

- **输入框**（RE4R）：不打开 REFramework 菜单也能点击输入框输入文字
- **燃烧伤害中**（RE4R）：被火焰攻击点燃时也会成立
- **鼠标光标**（RE4R）：面板打开时游戏不再隐藏鼠标光标
