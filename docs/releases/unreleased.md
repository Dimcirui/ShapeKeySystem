# ShapeKeySystem 1.5.0

### 面捕

进阶新增面捕页，用手机面捕驱动形态键和头部转动。游戏内直接接收数据，不需要另开转发程序。

- **方案**：支持 iFacialMocap、RhyLive 和通用 VMC
- **VMC**：ARKit 名字的表情按表情配置驱动，其他表情名直接写入模型上的同名形态键
- **头部转动**：带头部数据的方案同时转动头部；RhyLive 不带头部数据

## 新增

- **面部动画测试**：荒野可在游戏内录制面部表情，录完直接在面部动画测试中播放
- **表情**：新增「表情驱动」开关与「禁用骨骼表情」选项
- **条件规则**：状态的组合可选「-」临时停用
- **界面设置**：新增字体大小、可选的组合快捷键（Ctrl / Shift / Alt + Delete）和「打开菜单时屏蔽游戏操控」

## 变更

- **荒野**：做手势时由面部骨骼补上张嘴、眨眼和笑
- **过场与读盘**：读盘、换装和过场期间持续驱动，切镜头时表情不再中断
- **扫描**：默认始终搜索整个场景，扫描间隔默认 5 秒
- **表情配置**：不再随扫描自动切换，改用「自动匹配」按钮切换
- **设置**：设置页拆成界面设置与 SKS 设置，绑定与配置文件移到「总体绑定与配置」页

## 修复

- **条件规则**：重扫部件或战斗中受击时，受伤判定不再丢失
- **表情页**：重载脚本后面部导航图不再丢失
