## 新增

- **怪物猎人崛起**：支持做在防具部件里的 mod 头部，可捏脸、存取预设，表情跟随原版面部动作。
- **自动表情**：「表情详情」页新增自动眨眼、视线微动和待机时微微张嘴，可调频率、速度和幅度，并选择与游戏表情的合成方式。
- **形态键名字**：鬼武者、怪物猎人崛起、生化危机4 内置常见 VRChat / MMD 模型的形态键名，这类 mod 不用自带名字表也能显示键名。
- **名字表工具**：`tools/mesh_names.py` 从 mod 的 mesh 文件生成名字表，用于自定义命名的形态键。
