# ShapeKeySystem 1.9.0

## 新增

- **RE9（实验性）**：里昂默认主头部支持捏脸和普通场景的自动表情，包括眨眼、张嘴、眉毛、眼睑、唇部、嘴角、视线和元音口型；过场、其他角色、身体和头发尚未接入
- **表情配置自动匹配**：没有绑定配置、全局配置驱动不了身上的部件时，自动换成匹配最多的配置，MMD、VRC 命名的 mod 不用再手动点「自动匹配」
- **驱动（进阶）**：让任意形态键按正弦、三角、锯齿、方波、随机平滑波形或自己写的公式随时间循环变化，可设周期、相位和最低 / 最高值；面捕或其他插件正在控制的形态键会先让给它们

## 修复

- **RE4 模型鉴赏**：鉴赏中的里昂、艾达雕像会被识别，捏脸、驱动等直接作用于正在展示的雕像，里昂的其他服装头部也能识别
