# ShapeKeySystem 1.15.0

## ⚠️ 不兼容变更

- **条件规则**：命中的状态现在同时生效，下面的状态会补上面的状态没用到的形态键；想保持以前「只播放最上面一个」的效果，给上面的状态开启新的「独占状态」开关

## 新增

- **表情镜**：支持鬼武者 Way of the Sword；可按躯干、披风、武器隐藏，武器默认隐藏
- **条件（鬼武者）**：可用血量 %、掉血、回血、死亡、濒死、鬼变身、鬼力 %、鬼变身槽 %、奥义槽已满，开弓瞄准、弓快射、拔刀，战斗中、Boss 战中、锁定目标、主角说话、有人说话、菜单暂停、事件进行中，攻击、防御、弹刀、受击、倒地、闪避、空中、蹲伏、移动等动作状态，以及使用道具、跑墙、复活、死斗、吸收鬼门等动作
- **条件（荒野）**：新增集中模式、异常状态（睡眠、麻痹、晕眩、中毒、属性异常等，同时有多个时取最影响表情的一个，选「≠ 无」即任意异常）、时段、游戏内时间、天气，以及热饮或清凉饮生效、在临时营地帐篷里、在泥流里、拔刀或收刀动作中
- **导出为 mod**：「总体绑定管理 → 总体绑定」可以把当前生效的绑定、捏脸配置、表情配置、条件规则和驱动配置按当前的样子一起导出成 mod 包要带的文件，自动加作者前缀、改好互相引用

### 驱动

- 可以存多套驱动配置，在驱动页顶部切换、新建、另存为和删除，修改仍自动保存；以前的驱动自动变成「默认」配置
- 驱动页可以「设为默认」，穿上这套装备就切到这套驱动；手动切换的配置在换装之前一直有效
- mod 可以在 `mods/drivers/` 里自带驱动配置，并在绑定里指定用哪一套
- 公式可用 `cond(条件id)` 直接读游戏条件，不受条件规则的状态优先级影响；名为 `live` 的变量为 0 时放开下面的形态键，捏脸和键组照常显示

## 变更

- **表情（鬼武者）**：眨眼、睁大眼、眯眼、眉毛、笑、嘴角下拉和外拉、脸颊上提、张嘴和下唇下拉在 bsControl 不动时改读面部骨骼，主角说话时的自动嘴型也能驱动形态键。眼、眉、整个嘴部分区判断，区内有 bsControl 表情时只用 bsControl，不再被骨骼顶掉
- **面板**：顶部的普通提示显示 10 秒后自动消失，警告和错误仍需手动关闭
- **条件规则**：形态键配置组合从捏脸配置导入时，先选配置，再选「预设值」或某个键组选项，点「导入」加入；当前装备上一个形态键都对不上的配置不再列出
- **捏脸**：所有形态键默认都显示、都能搜到，表情通道、非预设通道和键组占用的键改成可选的隐藏开关；键组选中某个选项时，它占用的键标出被哪个键组占用，设为「无」时这些键可以照常调整，并回到你自己调的值，不再回到 mod 默认值
- **配置文件名**：名字含中文的捏脸配置、表情配置、条件规则和驱动配置，新建或另存时文件名只用英文和数字，不再乱码，换电脑也能读出；界面上仍显示原名
- **条件规则**：还没有形态键配置组合时也能添加状态，新状态先不绑定组合（「-」）

## 修复

- **崛起**：猎人动作时挂上的特效不再让形态键反复断开重连
